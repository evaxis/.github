# Evaxis organisation foundations

**Evidence Across Every Axis.**

This repository contains the [organisation profile](profile/README.md), shared
community health defaults and its own cARL governance.

| Repository | Purpose |
|---|---|
| [evaxis/evaxis](https://github.com/evaxis/evaxis) | Future independent core; planned contracts only |
| [evaxis/architecture](https://github.com/evaxis/architecture) | Principles, architectural records and roadmap |

**Confirmed:** foundation/design stage; no product services are implemented.
Evaxis is independent of Maester; integration is proposed, not established.
The existing organisation avatar is the canonical logo.

Read [contribution guidance](CONTRIBUTING.md), [support](SUPPORT.md),
[conduct expectations](CODE_OF_CONDUCT.md) and [security reporting](SECURITY.md).
Canonical agent governance is under `.github/carl/`; GitHub community-file
inheritance does not install cARL in other repositories.

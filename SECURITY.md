# Security reporting

Evaxis is in the foundation/design stage. There are no released product
versions or production services to support. Governance and repository security
issues are still welcome.

Use **Security -> Report a vulnerability** in the affected repository:

- [Organisation foundations](https://github.com/evaxis/.github/security/advisories/new)
- [Core](https://github.com/evaxis/evaxis/security/advisories/new)
- [Architecture](https://github.com/evaxis/architecture/security/advisories/new)

If the private reporting form is unavailable, contact the owner through
[their GitHub profile](https://github.com/goldjg) to arrange a private channel.
Do not post the report publicly while arranging contact.

Include affected paths or commits, a minimal non-sensitive reproduction and
expected impact. Never include live credentials, customer evidence, tenant
identifiers, personal information or exploit activity against third parties.
Coordinate disclosure with the maintainer; no response-time SLA or bug bounty
is promised. Do not open a public issue or PR containing a vulnerability.
